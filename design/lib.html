为什么选它

Why EventBus
⚡
Command + Query

命令分发与查询回传一套 API 搞定，进程内简易 CQRS，不需要消息队列的重量。

🧩
多 IOC 集成

Microsoft.DI / AspNetCore / DryIoc / Prism 开箱集成，还提供容器无关抽象。

🖥️
UI 框架无关

WPF、WinForms、Avalonia、ASP.NET Core、控制台通用，桌面与服务的公共层。

🚀
NativeAOT 友好

内置 AOT 验证工程，发布为原生单文件不踩反射的坑。

🪶
轻量可裁剪

核心包零第三方依赖，按需引入集成包，体积与依赖树都干净。

🔗
可升级到 IPC

需要跨进程时无缝升级到 EventBus.Socket（TCP 事件总线），API 风格一致。
